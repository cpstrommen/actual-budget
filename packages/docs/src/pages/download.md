---
title: Actual CFM Builds
---

Build Actual CFM from this repository to use this fork's changes. From the repository root:

```sh
yarn install
yarn start
```

For a production browser/server build, run `yarn build:server`. For a desktop build, run `yarn build:desktop`.

There are no separately published Actual CFM installers documented here. [Upstream Actual Budget downloads](https://actualbudget.org/download/) contain upstream builds and do not include CFM-specific changes. See the local [source-build guide](/docs/install/build-from-source) for the inherited build process.
