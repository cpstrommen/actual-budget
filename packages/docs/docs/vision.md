# Actual CFM Direction

Actual CFM is a personal fork of Actual Budget focused on annual financial planning, liquidity management, asset valuation, and net equity. The inherited ledger and monthly workflows support that broader view.

## Planning Priorities

- Compare annual category plans with YTD actual and expected spending.
- Understand whether available cash can cover short-term obligations.
- Track assets, investments, debt, receivables, and payables without confusing wealth with cash.
- Generate dated statements and report packages with traceable inputs and valuation assumptions.

These are planned additions. The repository's `wishlist.md` contains the implementation roadmap and acceptance criteria.

## Ownership and Origin

Data remains local-first, with optional synchronization and encryption. Actual CFM retains Actual CFM's MIT license and attribution. Upstream community governance and contribution policies do not apply to this personal fork.
