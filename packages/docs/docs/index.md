Actual CFM is a personal fork of Actual Budget for annual planning, cash flow management, liquidity, and asset valuation. The existing account, transaction, budgeting, and reporting features provide its foundation.

## Product Direction

The planned additions include annual category plans with YTD comparisons, asset valuations, receivables and payables, liquidity projections, and reusable financial report packages. These features are being planned; they are not yet implemented. The repository's root `wishlist.md` contains the implementation sequence and acceptance criteria.

## Using the Inherited Features

The guides in this site describe functionality inherited from Actual CFM. Monthly budgeting remains available while CFM features are developed. Start with [building from source](install/build-from-source.md) to run this fork. Upstream hosted services and downloads contain Actual Budget builds.

Use the sidebar or search to find account, transaction, budget, sync, and report guides. Historical upstream blog posts and release notes are retained outside the documentation site in the repository’s `archives/upstream/` directory.
